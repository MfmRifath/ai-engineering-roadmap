# G15 — Processing Sequences Using RNNs and CNNs

> **Thesis:** Recurrence gives a network memory by feeding its own output back as input — and
> that same loop is what makes it slow to train, hard to optimize, and ultimately unable to hold
> onto long context.

## Why this chapter matters

You are learning RNNs so you can understand why they were abandoned. Every architectural
compromise here — the sequential bottleneck, the vanishing memory, the gating machinery bolted on
to compensate — is a problem the transformer solves directly. Read this chapter as a list of
requirements for the thing that replaced it.

The two properties to hold onto: **RNNs cannot parallelize over time**, and **their memory decays**.

## Core concepts

### Recurrent neurons and unrolling

A recurrent neuron's output feeds back into itself at the next time step:

$$h_{(t)} = \phi(W_x^\top x_{(t)} + W_h^\top h_{(t-1)} + b)$$

The **hidden state** $h_{(t)}$ is the memory — a fixed-size summary of everything seen so far.
Unrolled through time, an RNN is a very deep feedforward network in which **every layer shares the
same weights**.

That fixed-size summary is the central limitation. Everything the model knows about a
1,000-token history must be compressed into one vector of a few hundred numbers, and it is
overwritten at every step.

### Sequence I/O patterns

| Pattern | Input → Output | Example |
|---|---|---|
| Sequence-to-sequence | seq → seq | Per-day stock prediction |
| Sequence-to-vector | seq → one | Sentiment classification |
| Vector-to-sequence | one → seq | Image captioning |
| **Encoder–decoder** | seq → vector → seq | **Translation** |

The encoder–decoder row is the important one historically. Encode the whole source sentence into
one vector, then decode from it. That single vector is the bottleneck **attention was invented to
remove** ([G16](ch16.md)).

### Training: BPTT and its costs

Backpropagation Through Time unrolls the network and backpropagates through every step. Two
consequences:

1. **No parallelism over time.** Step *t* needs step *t−1*'s output. Sequence length becomes
   sequential wall-clock time, and no amount of GPU helps.
2. **Deep gradient paths.** A 100-step sequence is a 100-layer backward pass with shared weights,
   so gradients vanish or explode readily.

> This is the whole reason transformers won. Self-attention computes all positions
> **simultaneously** as one matrix multiplication. That converts a sequential problem into a
> parallel one, and parallel problems scale with hardware.

### Baselines first

Géron's discipline is worth copying. On his time series:

| Approach | MSE |
|---|---|
| Naive (predict the last value) | 0.020 |
| Fully connected | 0.004 |
| Simple RNN (1 unit) | 0.014 |
| Deep RNN | 0.003 |

A single-unit RNN loses to a linear model. **Always establish the naive baseline first** — this
generalizes directly to LLM work, where "just prompt the model without RAG" is the baseline
people skip.

### Unstable gradients and the fixes

The usual toolkit ([G11](ch11.md)) applies with modifications:

- Good initialization, gradient clipping, **saturating** activations. Note the inversion: RNNs
  default to **tanh**, not ReLU, because an unbounded activation compounds explosively when
  applied repeatedly with shared weights.
- **BatchNorm does not work well** across time steps. **LayerNorm does**, because it normalizes
  within a single example. This is the same argument that makes LayerNorm the transformer's choice
  ([R4](../../03-build-llm-from-scratch-raschka/notes/ch04.md)).
- **Dropout** must use the *same* mask at every time step, otherwise the noise destroys the signal
  in the recurrence (`recurrent_dropout`).

### The short-term memory problem, and the gates

Information decays as it passes through the recurrence. A basic RNN effectively remembers ~10–20
steps.

**LSTM** adds a separate **cell state** $c_{(t)}$ that flows through the network with only
multiplicative and additive interactions — a highway for memory — plus three gates:

| Gate | Question it answers |
|---|---|
| **Forget** | What should I erase from the cell state? |
| **Input** | What new information should I write? |
| **Output** | What part of the cell state should I expose right now? |

Note what the cell-state highway is: a path along which information flows with minimal
transformation. **The same structural idea as ResNet's skip connection and the transformer's
residual stream.**

**GRU** simplifies to two gates and merges the cell and hidden states. Fewer parameters, faster,
usually comparable quality.

Both help enormously. **Neither solves the problem** — LSTMs manage perhaps 100 steps well. That
residual limitation is what motivates attention.

### 1D convolutions and WaveNet

You can process sequences without recurrence. A 1D convolution slides a kernel over time; stack
them and the receptive field grows.

**WaveNet** uses **dilated causal convolutions** — doubling the dilation rate each layer (1, 2, 4,
8, …), so 10 layers reach a receptive field of 1,024 steps. It is *causal* (only looks backwards)
and **fully parallel during training**.

Géron's WaveNet beats his LSTMs on the same task. That result is the real signpost: the winning
move was not better recurrence, it was **removing recurrence** so training could parallelize.
Attention took the same step further.

## Key code

```python
from tensorflow import keras

# return_sequences=True on every layer except the last, for stacked RNNs
model = keras.Sequential([
    keras.layers.LSTM(20, return_sequences=True, input_shape=[None, 1]),
    keras.layers.LSTM(20, return_sequences=True),
    keras.layers.TimeDistributed(keras.layers.Dense(10)),
])

# WaveNet: dilation doubling gives exponential receptive field growth
model = keras.Sequential()
model.add(keras.layers.InputLayer(input_shape=[None, 1]))
for rate in (1, 2, 4, 8) * 2:
    model.add(keras.layers.Conv1D(filters=20, kernel_size=2, padding="causal",
                                  activation="relu", dilation_rate=rate))
model.add(keras.layers.Conv1D(filters=10, kernel_size=1))
```

## Gotchas

- **Forgetting `return_sequences=True`** on intermediate RNN layers. You get the last output only,
  and the next layer receives a rank-2 tensor. A very common shape error.
- **ReLU in an RNN.** Unbounded activation applied repeatedly with shared weights explodes.
  Default to tanh.
- **BatchNorm across time steps.** Use LayerNorm instead.
- **Independent dropout masks per time step.** Use `recurrent_dropout` so the mask is shared.
- **Skipping the naive baseline.** A single-unit RNN can lose to "predict the last value."
- **`padding="same"` when you need causality.** For forecasting, use `padding="causal"` or you
  leak the future into the present — a subtle, devastating bug.
- **Expecting RNN training to speed up with a bigger GPU.** The time dimension is sequential.

## Flashcards

<!-- card -->
Q: Why can't RNN training be parallelized over time?
A: The hidden state at step t depends on step t−1, so steps must run in order. Sequence length becomes sequential wall-clock time regardless of hardware. Self-attention removes this by computing all positions simultaneously as one matrix multiply.
<!-- /card -->

<!-- card -->
Q: What are an LSTM's three gates?
A: **Forget** (what to erase from the cell state), **input** (what new information to write), and **output** (what part of the cell state to expose at this step). The cell state itself flows through with only multiplicative and additive interactions — a memory highway.
<!-- /card -->

<!-- card -->
Q: Why do RNNs use tanh rather than ReLU by default?
A: The same weights are applied repeatedly through time, so an unbounded activation compounds and explodes. A saturating activation keeps the recurrence stable.
<!-- /card -->

<!-- card -->
Q: Why LayerNorm rather than BatchNorm in an RNN?
A: BatchNorm's statistics are computed across the batch and do not behave sensibly across time steps or variable-length sequences. LayerNorm normalizes within a single example, so it is independent of batch composition — the same reason transformers use it.
<!-- /card -->

<!-- card -->
Q: What is a dilated causal convolution, and what does WaveNet do with it?
A: A 1D convolution that skips inputs at a fixed rate and only looks backwards in time. WaveNet doubles the dilation each layer (1, 2, 4, 8, …), so 10 layers reach a 1,024-step receptive field — with fully parallel training and no recurrence.
<!-- /card -->

<!-- card -->
Q: What lesson does WaveNet beating LSTMs teach about architecture?
A: The winning move was not better recurrence but **removing recurrence**, so training could parallelize. Attention took the same step further, which is why transformers replaced RNNs.
<!-- /card -->
